# Ground Control Points (GCP) file (optional)

Licence/terms: vendor documentation, copyrighted, excerpt only

Supports:
> "Ground Control Points (GCP) file (optional) The GCPs are points of the area to map with known coordinates."
> "3D GCPs WGS84 geographic coordinates label,latitude[decimal degrees],longitude[decimal degrees],altitude[meter] Example: GCP0,46.23456,6.56114,299.931 GCP1,46.23234,6.56234,299.823 The latitude value is between -90° and 90°."
