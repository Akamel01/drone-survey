Available Functions (EssentialFunctionSet)

Functions available in the EssentialFunctionSet set.

Using 

Sets the chosen function set as a global scope in the template, enabling all functions, variables, and expressions from that set. Multiple function sets can be used in a template, but each one must be invoked separately.

Syntax: 

$Using( "CapturingReality.Report.FunctionSet" ) 

Possible inputs  (function set names):
