Download and Install the Epic Games Launcher 

The Epic Games Launcher is where you download and manage your RealityScan versions. The launcher also gives you access to the Epic Games Store and professional development tools such as Unreal Engine, Fab, and Twinmotion.

To download and install the Epic Games Launcher, follow these steps:

Access the Download RealityScan page.

Click the Download Launcher button to download the installer file. Alternatively, you can click the Download button in the top-right corner of the page  

Depending on your browser presets, a pop-up window may ask where you’d like to save the installer file. Alternatively, it may automatically save to the Downloads folder on your computer. 

After the download is complete, execute the installer file to run the Setup Wizard.

Depending on your system settings, you may be asked to approve security prompts before the Setup Wizard can start.  

Once the Setup Wizard is complete, open the Epic Games Launcher .

Install and Run RealityScan 

Once the Epic Games Launcher is open, you’ll be prompted to sign in using an Epic Games account. You can  sign in with an existing Epic Games account  or  create an Epic Games account .  You won't be able to install RealityScan without an account.

To install the latest version of RealityScan, follow these steps:

In the Epic Games Launcher, click Unreal Engine in the left-hand navigation panel. This displays tabs relevant to Unreal Engine where RealityScan can be found.

Click the RealityScan tab. This is where you install and launch RealityScan.

Select the version you want to install. By default, the latest version of RealityScan is selected. 

After selecting a version, press the Install button.

Read through the RealityScan Pricing options . Click Accept to proceed.

Read through the RealityScan End User License Agreement. Check the checkbox to indicate that you’ve read and agree with the terms. Click Accept to proceed.  

You must accept all shown agreements in order to download RealityScan. If you click Dismiss you won't be able to download.

To choose where to install RealityScan on your hard drive, click Browse in the Choose install location dialog. By default, RealityScan uses the default installation location for your operating system.  

In the Choose install location dialog, click Install. 

Once RealityScan is installed, press the Launch button to run RealityScan.
